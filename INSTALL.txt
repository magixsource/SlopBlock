SlopBlock 安装说明

1. 把这个 ZIP 解压到一个固定的文件夹（请不要删除该文件夹，Chrome 会一直从这里加载扩展）。
2. 打开 Chrome，在地址栏输入 chrome://extensions 并回车。
3. 打开页面右上角的「开发者模式」开关。
4. 点击「加载已解压的扩展程序」，选择解压后包含 manifest.json 的那个文件夹。
5. 完成后可在浏览器工具栏的扩展菜单里把 SlopBlock 固定显示。

更新方法：下载新版 ZIP 后解压到新文件夹，重复第 4 步加载新版，然后删除或禁用旧版本。

注意：从 Chrome 133 起，以「已解压」方式加载的扩展必须在开发者模式开启时才会启用。

SlopBlock installation

1. Extract this ZIP to a permanent folder.
2. Open chrome://extensions in Chrome.
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and select the extracted folder that contains manifest.json.
5. Pin SlopBlock from the extensions menu in the toolbar.
